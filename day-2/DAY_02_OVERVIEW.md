# Day 2: Control Flow, Data Structures, Loops, and Functions

## Welcome to Day 2
Day 2 transitions from fundamental data primitives into programmatic logic, complex data organization, and procedural modularity.

---

## Daily Schedule & Module Breakdown

| Module | Title | Key Topics Covered |
| :--- | :--- | :--- |
| **Module 5** | **Conditional Logic and Flow Control** | • Booleans & Comparison Operators (`==`, `!=`, `<`, `>`, `<=`, `>=`)<br>• Identity vs Equality (`is` vs `==`)<br>• Branching (`if`, `elif`, `else`), Ternary Operators (`x if c else y`)<br>• Short-Circuit Evaluation (`and`, `or`, `not`)<br>• Coding Challenges: Tiered Pricing & RBAC Access Control |
