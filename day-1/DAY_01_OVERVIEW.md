# Day 1: Python Fundamentals & Core Mechanics

## Welcome to Day 1
Day 1 sets the foundational bedrock for the entire 3-day Python Essentials course. We transition from algorithmic problem-solving concepts into writing clean, idiomatic Python code.

---

## Daily Schedule & Module Breakdown

| Module | Title | Key Topics Covered |
| :--- | :--- | :--- |
| **Module 1** | **Introduction to Python** | • Logic and Algorithm Basics<br>• Overview of the Programming World (Interpreted vs Compiled)<br>• Environment Setup & Package Management (`venv`, `pip`)<br>• IDEs: IDLE, VS Code, Jupyter Notebooks, Google Colab |
| **Module 2** | **Core Concepts: Variables & Data Types** | • Python Variable Architecture & PEP 8 naming<br>• Dynamic Typing & Memory References (`id()`, `is` vs `==`)<br>• Primitive Types: `int`, `float`, `str`, `bool`, `NoneType`<br>• Type Casting & Implicit Coercion |
| **Module 3** | **Numeric in Python** | • Integers, Arbitrary Precision, and Float Quirks (IEEE 754)<br>• Arithmetic, Modulo (`%`), Floor Division (`//`), PEMDAS<br>• Python `math` module & High-Precision Calculations<br>• Hands-On Mini Project: Financial & Geometric Calculators |
| **Module 4** | **String Manipulation** | • Strings as Immutable Sequences, Indexing & Slicing (`[start:stop:step]`)<br>• Essential String Methods (`split`, `join`, `strip`, `replace`, etc.)<br>• String Interpolation (f-strings, `.format()`, `%`)<br>• Hands-On Project: Text Cleaner & Data Sanitizer |

## Prerequisites & Setup Checklist
Before starting Day 1:
1. Ensure Python 3.10+ (preferably 3.11 or newer) is installed:
   ```bash
   python --version
   ```
2. Verify that your editor/IDE is configured (VS Code with Python extension, Jupyter, or IDLE).
3. Test running a script from your command line:
   ```bash
   python -c "print('Ready for Python Essentials!')"
   ```
